Présentation du projet : Personnages qui lancent des projectiles via des compétences à rechargement. <br>
Organisation : Dossiers majeurs : Assets contenant les dossiers liés aux assets 3D, Prefabs, Scripts et ScriptableObject pour les composants éponymes. Tout les dossiers sont regroupés dans le dossier _Project.  <br>
Fonctionnalités : ScriptableObject pour créer des capacités aux dégâts, VFX, projectile et nom personnalisables, pour chaque capacité un bouton est automatiquement créé pour pouvoir l'utiliser, cooldown visuel sur l'UI des boutons.  <br>
Les capacités font apparaitre des projectiles qui se dirigent vers un ennemi subissant des dégâts (barre de vie smooth et état de mort).
Installation : unity 6000.3.18f1  <br>
