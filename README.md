Présentation du projet : Personnages qui lancent des projectiles via des compétences à rechargement.  \n
Organisation : Dossiers majeurs : Assets contenant les dossiers liés aux assets 3D, Prefabs, Scripts et ScriptableObject pour les composants éponymes. Tout les dossiers sont regroupés dans le dossier _Project.  \n
Fonctionnalités :  \n
Installation : unity 6000.3.18f1  \n
Assets externes : KayKit Adventurers, personnages 3D, appartient à Kay Lousberg, récupéré sur itch.io, lien : https://kaylousberg.itch.io/kaykit-adventurers  \n
KayKit Character Animations, animations de déplacement et de combat des personnages, appartient à Kay Lousberg, récupéré sur itch.io, lien : https://kaylousberg.itch.io/kaykit-character-animations \n
Magic Effects FREE, pack d'effets visuels, appartient à Hovl Studio, récupéré sur l'asset store, lien : https://marketplace.unity.com/packages/vfx/particles/spells/magic-effects-free-247933  \n
Hit Effects FREE, pack d'effets d'impact, appartient à Matthew Guz, récupéré sur l'asset store, lien : https://assetstore.unity.com/packages/vfx/particles/hit-effects-free-284613  \n
DOTween, bibliothèque d'animations pour les déplacements et l'interface, lien : https://dotween.demigiant.com  \n
